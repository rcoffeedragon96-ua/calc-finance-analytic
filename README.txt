-------------------------------------------------------------------------------
ВАРІАНТ 1. ШВИДКИЙ ЗАПУСК БЕЗ СЕРВЕРА (В БРАУЗЕРІ):
-------------------------------------------------------------------------------
Просто двічі клікніть на файл `bess_calculator.html` і відкрийте його в Chrome, 
Edge, Safari або Firefox. Усі розрахунки, кабінет, адмін-панель та звіт працюють одразу.

-------------------------------------------------------------------------------
ВАРІАНТ 2. ЗАПУСК КЛІЄНТ-СЕРВЕРНОГО SAAS-СЕРВЕРА (ЗАКРИТИЙ БЕКЕНД):
-------------------------------------------------------------------------------
1. Переконайтеся, що на комп'ютері встановлені Python (>= 3.10) та Node.js (>= 18).
2. Встановіть залежності (одноразово в терміналі):
   pip install -r requirements.txt
3. Запустіть сервер:
   - У Windows: двічі клікніть на `run_server.bat`
   - У Linux / Mac: sh run_server.sh
   Або вручну в командному рядку:
   uvicorn bess_backend_server:app --host 0.0.0.0 --port 8000 --reload
4. Відкрийте у браузері: http://localhost:8000
